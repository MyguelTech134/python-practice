# Object-Oriented Programming in Python

This folder contains my exercises from Gustavo Guanabara's Python OOP course on [Curso em Vídeo](https://www.youtube.com/watch?v=Mim6nnkdOto).

I'm using these exercises to practice classes, objects, attributes, methods, and how objects work together.

The course is in Portuguese, but I write my code in English to practice both.
