# Python Exercises

This repository contains the exercises I work on while learning Python.

My goal is to strengthen my problem-solving skills, practise Python fundamentals, and track my progress through exercises of increasing difficulty.

## Planned Topics

- Input and output.
- Variables, calculations, and conditions.
- Loops: `for` and `while`.
- Lists, tuples, and dictionaries.
- Functions and code organisation.
- Input validation and error handling.

## How to Run

Python 3 must be installed on your computer.

1. Download the repository files.
2. Choose the exercise you want to run.
3. Open its `.py` file in your Python editor and run it.
